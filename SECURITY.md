# Security

If you find a security problem in Quick Dial NG, please report it privately: on the repository's **Security** tab, click **Report a vulnerability** ([direct link](https://github.com/YuriyWozniak/quickdial-ng/security/advisories/new)). Please don't open a public issue for it.

Fixes go into the latest version only, which Firefox installs automatically from addons.mozilla.org or from GitHub Releases.
